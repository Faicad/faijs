# faijs `.fai.zip` 容器格式规范

[English](fai-zip-format.md) | 中文

> 定位：本文档是 `.fai.zip` 容器格式的**规范** —— faijs 模型图的打包格式。它定义归档规则、成员模型（必填、条件必填、可选）、`manifest.json` schema、入口与模块解析、数据成员与资产成员、合格读取方与写入方的义务，以及版本策略。格式与实现无关：任何第三方可以只依据本文档实现自己的读取方或写入方。
>
> 相邻：[`docs/api-contract.zh.md`](api-contract.zh.md) 是接口契约（脚本 API、宿主注入、执行）；[`docs/syntax-design.zh.md`](syntax-design.zh.md) 是 `.fai.js` 语法与增量执行契约；[`docs/reproducibility-contract.zh.md`](reproducibility-contract.zh.md) 是几何确定性契约；[`docs/ops-api-inventory.zh.md`](ops-api-inventory.zh.md) 是 op 手册。本文档不追踪开发计划与缺陷，也不引用 `docs/plans/` 文档。

## 1. 范围与合格性

`.fai.zip` 容器打包一个或多个**模型**：每个模型是一份 faijs 入口脚本，外加记录"脚本推不出来那部分内容"的数据成员（可选）。容器同时携带这些脚本引用到的文件字节与资产字节。它是多文件 faijs 工程的打包格式，也是 faijs 唯一定义的容器格式。

**必须**（MUST）、**不得**（MUST NOT）、**应当**（SHOULD）、**可以**（MAY）为规范用语。合格性按角色定义，不按具体实现定义：

| 角色 | 要求 |
|---|---|
| 读取方 | 加载容器，重建其模型、数据与资产（§9） |
| 写入方 | 产出容器（§10） |

读取方**不得**假设写入方是谁：它加载的容器可以来自任何工具，包括他人编写的工具。写入方**不得**假设读取方是谁。

## 2. 容器与成员命名

容器是一个文件名以 `.fai.zip` 结尾的 ZIP 归档。除此之外没有任何东西标识它：后缀是命名约定，真正的标识是 `manifest.json`（§4）。

成员路径**必须**用 `/` 作分隔符，**必须**是相对路径，且**不得**含前导 `/`、盘符、`..` 段或反斜杠。成员路径是 UTF-8 且区分大小写：`model/Plate.fai.js` 与 `model/plate.fai.js` 是两个不同的成员。

成员**可以**使用格式允许的任意 ZIP 压缩方式（store、deflate）；读取方**必须**两者都接受。不支持加密成员：写入方**不得**写出加密成员，读取方遇到加密成员**必须**报错，而不是索要口令。资源上限（归档大小、成员数量、解压后大小）由实现自定；强制上限的读取方**必须**报错并指明该上限，而不是部分加载一个容器。

## 3. 成员模型

成员的类别由"缺失时读取方必须做什么"决定，除此之外不决定别的。

| 成员 | 类别 | 缺失时的读取方义务 |
|---|---|---|
| `manifest.json` | 必填 | 报错。没有可读 manifest 的容器不是容器 |
| `model/**/*.fai.js` | 必填 | `models[].entry` 指名的成员缺失报错；其余 `.fai.js` 成员构成模块图（§5） |
| `data/**` | 条件必填 | `models[].data` 指名的成员缺失报错；该命名空间下的其它成员不要求存在 |
| `files/**` | 条件必填 | 模型脚本引用了该成员的 key 时缺失报错（§7）；否则不要求存在 |
| `assets/**` | 条件必填 | 模型脚本引用了该成员的 key 时缺失报错（§7）；否则不要求存在 |
| `preview/**` | 可选，标准命名空间 | 没有预览可用。不是错误 |
| `export/**` | 可选，标准命名空间 | 没有预导出产物可用。不是错误 |
| `cache/**` | 可选，标准命名空间 | 重新计算。不是错误；读取方**可以**删除该命名空间 |
| `mapping.json` | 可选，FCStd 转换约定 | 没有保真账本可用。不是错误 |
| `freecad/**` | 可选，FCStd 转换约定 | 没有源字节影子可用。不是错误 |
| 任何其它成员 | 可选，写入方自定义 | 忽略。不是错误 |

不存在"表外成员即违规"这条规则：写入方**可以**增加成员，读取方**必须**忽略它不消费的每一个成员。类别约束的是反方向 —— 缺了就重建不出来的必填或条件必填成员，是容器的缺陷，永远不是让读取方去猜的情形。

## 4. `manifest.json`

manifest 是一个 UTF-8 JSON 对象：

```jsonc
{
  "format": 3,
  "units": "mm",
  "models": [
    { "id": "plate", "entry": "model/plate.fai.js", "label": "Plate", "data": "data/plate.json" },
    { "id": "bracket", "entry": "model/bracket.fai.js" }
  ],
  "active": "plate",

  "createdAt": "2026-09-27T10:00:00.000Z",
  "appVersion": "0.18.3",
  "label": "Engraved import",

  "source": { "file": "Beds.FCStd", "programVersion": "0.21.1", "schemaVersion": 4 },
  "requiresBrep": true
}
```

| 字段 | 是否出现 | 类型 | 含义 |
|---|---|---|---|
| `format` | 必填 | integer | 容器格式标识；本修订为 `3`（§11） |
| `units` | 必填 | string | 容器内所有坐标的单位；`"mm"` |
| `models` | 必填 | array，长度 ≥ 1 | 完整模型清单（§5） |
| `models[].id` | 必填 | string | 模型标识：容器内唯一，不含 `/` 与 `\` |
| `models[].entry` | 必填 | string | 该模型入口脚本的容器内路径 |
| `models[].label` | 可选 | string | 显示名。读取方**不得**把它当标识使用 |
| `models[].data` | 可选 | string | 该模型数据成员的容器内路径（§6）。缺省 = 该模型没有数据成员 |
| `active` | 可选 | string | 初始激活模型的 `models[].id`。缺省 = `models[0]` |
| `createdAt` | 可选 | string | ISO 8601 时间戳。仅供展示 |
| `appVersion` | 可选 | string | 产出工具的版本。仅供展示 |
| `label` | 可选 | string | 容器显示名。仅供展示 |
| `source` | 可选 | object | FCStd 转换溯源（§8.2）。仅供展示 |
| `requiresBrep` | 可选 | boolean | 该模型图要求 BREP 链（§8.2） |

规则：

1. `format` **必须**是整数 `3`。读取方遇到其它值**必须**报错并指明观察到的值；**不得**解释它、升级它，或部分读取该容器。
2. `units` **必须**是 `"mm"`。坐标与角度约定本身由 [`docs/api-contract.zh.md`](api-contract.zh.md) 负责。
3. `models[].id` 的取值**必须**唯一，`models[].entry` 的取值**必须**唯一且**必须**解析到 `model/` 下真实存在的成员。
4. `active` 出现时**必须**等于某个 `models[].id`；否则容器非法。
5. `models[].data` 出现时**必须**解析到真实存在的成员；指名的数据成员缺失是缺陷，不是"回落到约定路径"的情形。
6. 本规范未定义的字段，读取方**必须**忽略。写入方**不得**用未定义字段改变已定义字段的含义。
7. manifest 是声明，不是缓存：任何字段都**不得**写出一个读取方能通过读它指向的成员而推翻的值。

## 5. 模型、入口与模块解析

**模型**是一份入口脚本，外加一份数据成员（若已声明）。模型是宿主列出、执行、切换的单位；`models` 是完整清单，`model/` 下未被 `models[]` 指名的成员不是模型。

**模块**是 `model/` 下任何 `.fai.js` 成员。成员的**模块 key** 是它在容器内相对 `model/` 的路径：`model/plate.fai.js` 的 key 是 `plate.fai.js`，`model/parts/a.fai.js` 的 key 是 `parts/a.fai.js`。

规则：

1. 每个 `models[].entry` **必须**是 `model/` 下以 `.fai.js` 结尾的成员。
2. 模块内的相对 import 说明符以引入方的 key 为基准解析：`./x.fai.js` 与 `../x.fai.js` 相对引入方所在目录，前导 `/` 表示从 `model/` 根开始的 key。解析会消解 `.` 与 `..` 段，得到一个模块 key。脚本文本与 import 语法由 [`docs/syntax-design.zh.md`](syntax-design.zh.md) 负责。
3. 解析结果不是 `model/` 下真实存在的 `.fai.js` 成员时，**必须**报错。裸说明符（不以 `.`、`..` 或 `/` 开头）根本不指向容器成员：它是库引用，而库不属于本规范。
4. 入口选择是静态的：激活模型是 `models[].id === active`，`active` 缺省时为 `models[0]`。读取方**不得**按文件名模式、成员顺序或时间戳选择入口。
5. 执行一个模型**不得**需要 `model/**`、`files/**`、`assets/**` 与该模型自己的数据成员之外的东西。多个模型**可以**共用模块与资产，**不得**共用一个数据成员。

## 6. 数据成员

数据成员记录的是"单纯重跑脚本复现不出来"的东西：叠加在重建结果之上的用户编辑决策，例如显示名、显隐、材质、变换，以及导入文件的记录。

规则：

1. 数据成员是 UTF-8 JSON 对象。二进制载荷**不得**内嵌其中，也**不得**要求它旁边存在配套成员：载荷放在 `files/**` 或 `assets/**`（§7），按 key 定位。`data/**` 下不是 JSON 的成员非法。
2. 本规范不定义数据成员的键。它们由写出它的工具负责。读取方**必须**忽略自己不认识的键，且**不得**把不认识的键当作错误。
3. 模型的脚本文本只存在于它的入口成员与 `model/**` 下的模块里。数据成员**不得**携带脚本的副本。
4. 数据成员是重建结果之上的叠加，永远不是结果的来源：删掉所有数据成员后，各模型仍**必须**能执行并产出几何（模型可以丢掉编辑叠加，但不丢几何、不丢身份）。
5. 没有 `models[].data` 的模型就没有数据成员。读取方**不得**按约定路径去找数据成员。

## 7. 资产成员

载荷字节放在两个命名空间：`files/**` 放用户导入模型的文件字节，`assets/**` 放脚本直接消费的字节（BREP 载体、轮廓描述、图片）。两者的寻址方式相同。

成员的**资产 key** 是其基本名去掉最后一段扩展名：`assets/bracket.brp` 的 key 是 `bracket`，`files/9f1c2a.bin` 的 key 是 `9f1c2a`。这与 faijs 文件系统资产解析器作用于目录时的规则相同，因此解包后的容器与打包的容器寻址同一批载荷。

规则：

1. key 在 `files/**` 与 `assets/**` 合起来看**必须**唯一。读取方遇到重复 key **必须**报错并指出两个成员，**不得**二选一。
2. 模型脚本按 key 引用资产。脚本引用的 key 没有成员提供时，加载**必须**报错并指明该 key。读取方**不得**替换成别的成员、**不得**去远端抓取、也**不得**带着空几何继续。
3. 扩展名由写入方自定，除 key 规则外不带含义：解析只按 key，绝不按扩展名或内容嗅探。
4. 这两个命名空间**应当**保持平铺：任意深度的成员都按基本名取 key，所以使用子目录的写入方仍须保证基本名唯一。
5. 字节对容器是不透明的：读取方**必须**把它们交给按 key 索取的那个消费方，**不得**自行改写、转码，或按自己挑选的格式做校验。

## 8. 可选命名空间

### 8.1 标准命名空间

想让容器在不执行脚本时也起作用的写入方，**可以**增加这些成员。它们的路径即契约；没有 manifest 字段来声明它们。

| 路径 | 内容 |
|---|---|
| `preview/thumbnail.<ext>` | 容器级预览图 |
| `preview/<modelId>.<ext>` | 单个模型的预览图 |
| `export/<modelId>.<ext>` | 单个模型的导出产物（STEP、STL、3MF 等） |
| `cache/<modelId>/**` | 单个模型的执行缓存 |

义务：

1. 读取方**可以**使用这些命名空间的成员，且**不得**要求它们存在。
2. 写入方**不得**让必填或条件必填成员依赖它们中的任何一个。
3. 删掉这些命名空间的全部成员后，**必须**剩下一个描述同样模型、同样几何、同样身份的容器。这就是一个命名空间要成为可选所须满足的唯一边界：它可以改变加载的成本，永远不能改变结果。

### 8.2 FCStd 转换约定

FCStd → `.fai.zip` 转换器会写出额外的成员，用于记录一次转换的保真情况。它们是该转换器的约定，不是对任何其它写入方的要求；没有它们的容器同样是合格的。

| 成员 | 内容 |
|---|---|
| `mapping.json` | 逐对象保真账本：每个源对象一条，含 disposition（`translated`、`baked`、`preserved-only`）、未翻译时的原因，以及它产出的 artifacts |
| `freecad/**` | 源文档归档全体成员的字节级影子；转换不丢弃任何源字节 |
| `assets/*.brp` | 烘焙的 BREP 载体，由转换后的脚本经平台 BREP 资产导入 op 引用 |
| `manifest.source` | 溯源：源文件名、产出程序版本、文档 schema 版本 |
| `manifest.requiresBrep` | 模型图要求 BREP 链时为 `true` —— 烘焙载体没有 mesh 解析器，因此无法提供 BREP 链的宿主必须报错，不得静默改走 mesh 路径 |

## 9. 读取方义务

1. **自足。** 重建**必须**只依赖声明真正点名的成员：`models[].entry`、`models[].data`，以及脚本按 key 引用的 `files/**` 或 `assets/**` 成员。把没有任何声明引用的成员全部删除后 —— `preview/**`、`export/**`、`cache/**`、`mapping.json`、`freecad/**` 以及任何写入方自定义成员 —— 重建**必须**仍然成功。删除一个数据成员就要连它的声明一起删：留着声明却指向不存在的成员是缺陷，不是"恰好缺失的可选成员"。
2. **忽略未知。** §3 未列出的成员、§4 未列出的 manifest 字段、读取方未定义的数据成员键，**必须**被无错忽略。
3. **缺陷即报错。** `manifest.json` 缺失或非法、`format` 不等于 `3`、`models` 数组非法、入口不存在、相对 import 解析不到、脚本引用的资产 key 无成员提供、资产 key 重复、指名的数据成员缺失 —— 每一条**必须**报错并携带出错的路径或 key。
4. **不猜。** 入口选择是 `active` 或 `models[0]`（§5.4）。读取方**不得**回落到文件名启发式、成员顺序或时间戳。
5. **可选成员不参与任何判定。** 缓存几何、预览、导出产物**不得**被当作模型几何加载，也**不得**用来跳过或替代一次执行。
6. **不做远端替代。** 成员引用**必须**在归档内满足；读取方**不得**为满足某个引用去抓取远端资源。
7. **报告而不修补。** 读取方**不得**改写它加载的容器，也**不得**静默丢弃自己消费不了的成员。

## 10. 写入方义务

1. **声明。** 写出 `manifest.json`，含全部必填字段、`format` 等于 `3`、`units` 等于 `"mm"`。
2. **交付被引用者。** manifest 字段、模块 import、数据成员、资产引用所点名的每个成员都要写出。被引用的成员写不出来时，写入方**必须**失败，而不是产出一个读取方重建不出来的容器。
3. **完整。** 写出入口图里的每个模块，包括只被嵌套 import 触及的模块。容器**不得**依赖只存在于撰写机器上的文件。
4. **与位置和机器无关。** 任何成员都**不得**为表达含义而要求归档之外的文件系统路径、撰写机器上的成员，或该机器的时钟。
5. **身份唯一。** `models[].id`、`models[].entry` 与资产 key 在容器内**必须**各自唯一。
6. **让可选的保持可选。** 每个可选成员被删除后，**必须**不改变容器的模型、几何与身份（§8.1）。
7. **宁失败，不静默。** 静默丢失 —— 写入方不报错就丢掉的源对象、被引用的载荷或编辑决策 —— 是写入方的缺陷。

## 11. 版本与变更策略

`format` 是容器格式标识：一个整数，指代成员模型、manifest schema 与解析规则的一个修订。

1. 破坏性变更 —— 成员语义、必填字段含义、key 规则或解析规则 —— **必须**升 `format`。
2. 增量变更**不得**升 `format`：新增可选命名空间、新增可选 manifest 字段、新增可选成员，在当前取值下都是合格的，因为读取方本就会忽略它不消费的成员与字段。
3. 本规范不定义迁移，也不定义协商。`format` 不受支持的容器**必须**被拒绝并报错指出观察到的值；按别的规则解释它、升级它，或部分读取它，都违反 §9.3。
4. 读取方**不得**从成员是否存在、成员数量、工具元数据或时间戳推断格式修订。

## 12. 最小合格容器

```
example.fai.zip
├── manifest.json
└── model/
    └── plate.fai.js
```

```json
{
  "format": 3,
  "units": "mm",
  "models": [{ "id": "plate", "entry": "model/plate.fai.js" }]
}
```

这个容器只有一个模型、没有数据成员、没有资产。合格的读取方以它为激活模型执行 `model/plate.fai.js` 并重建其几何；合格的读取方同样能加载在此基础上加了任意可选成员的同一容器，并保持没有它们时的模型、几何与身份不变。
