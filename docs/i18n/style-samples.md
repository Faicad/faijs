# Style Samples

Translation style samples for consistent voice across the bilingual corpus.

## English → Chinese

### Technical description

**English:**

The BREP chain executes exact geometric operations via OCCT solids. STEP export produces `ADVANCED_FACE` geometry.

**Chinese:**

BREP 链通过 OCCT 实体执行精确几何运算。STEP 导出产生 `ADVANCED_FACE` 几何。

### Code reference

**English:**

Use `cad.box({ w: 10, h: 20, d: 5 })` to create a rectangular prism. The `w` parameter sets the width along the X axis.

**Chinese:**

使用 `cad.box({ w: 10, h: 20, d: 5 })` 创建长方体。`w` 参数设置沿 X 轴的宽度。

### Warning / convention

**English:**

**BREP path availability is determined by static rules before execution, not by runtime try-catch.**

**Chinese:**

**BREP 路径是否可用，由静态规则在执行前判定，不是运行时 try-catch 判定。**
