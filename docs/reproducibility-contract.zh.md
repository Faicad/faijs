# faijs 可重现性契约

[English](reproducibility-contract.md) | 中文

> 定位：本文档是 `.fai.js` 交换格式的**确定性契约** —— 约定同一份源码如何跨时间、跨几何内核、跨 JavaScript 引擎产出相同的几何。它定义"几何相同"的精度界、几何数据与非几何数据的边界、非确定源集合、判断非确定值是否到达几何的静态分析，以及引擎与宿主的责任。
>
> 相邻：[`docs/api-contract.zh.md`](api-contract.zh.md) 是接口契约（身份、语句模型、执行、几何分派）；[`docs/language-design.zh.md`](language-design.zh.md) 是语言与增量执行契约。本文档不追踪开发计划与缺陷，也不引用 `docs/plans/` 文档。

---

## 1. 目标与范围

### 1.1 可重现性

`.fai.js` 是可执行交换格式，保留建模者的意图与参数化能力。其可重现性保证只对**几何数据**成立：

> 同一份源码，在任意符合本契约的环境（任意几何内核、任意 ECMAScript 实现）下重执行，产出的几何在 §1.3 的精度界内相等。

非几何输出（日志、计时、调试）不在保证范围。

### 1.2 几何数据边界（sink）

只有三类值构成几何数据。非确定值流入其中任意一类即构成违约。

| Sink | 决定什么 | 示例 |
|---|---|---|
| 几何参数 | 决定形状 / 变换 / 拓扑的数值实参 | `cad.box(w,h,d)`、`cad.sphere({radius})`、`cad.translate(part,{offset})`、`nRad`、旋转角度 |
| 几何结构 | 决定执行哪个 op 及其组合方式的控制流（隐式流） | 在两次 `cad.union(...)` 结果间做选择的分支条件 |
| 身份 | 写进导出文件的名称 / 标识 | part 命名、约束名、文档对象 `name/id`、内容哈希输入 |

`console.log`、计时、异常堆栈不是 sink。

### 1.3 精度（"几何相同"）

换内核 / 换引擎后的重执行存在末位 ulp 浮点差异，因此"相同"意味着**对齐到小数点后 5 位（1e-5）**，分三类容差：

| 类别 | 容差 | 适用 |
|---|---|---|
| 长度 | 绝对 1e-5 mm | 顶点坐标、距离、偏移、bbox 边长 |
| 归一化量 | 绝对 1e-5 | 法向、单位四元数分量、单位方向 |
| 体积 / 面积 | 相对 1e-5 | `volume`、`surfaceArea` |
| 角度 | 绝对 1e-5 度 | 旋转角、夹角 |

该界同时作为 §5 出口校验的比对阈值。

## 2. 非确定源

以下 API 的调用结果视为非确定（tainted）。某个具体用法是否违约由 §3 判定；源本身不一律禁止。

| 源 | 非确定原因 |
|---|---|
| `Math.random` | 运行时随机 |
| `Date.now()` / `new Date()`（无参或依赖系统时钟） | 当前时间 |
| `new Date(...)` 依赖时区/本地化 | 环境时区 |
| `crypto.getRandomValues` / `crypto.*` | 运行时随机 |
| `performance.now` | 单调时钟 |

## 3. 静态污染分析

`Date` 调用是否最终流入几何生成，由静态数据流污染分析判定。

### 3.1 源、汇、规则

- **源**：§2 中的 API 调用。
- **汇**：§1.2 的三类 sink。
- **判定**：存在一条从源到汇的传播路径，即违约（`E_NONDETERMINISTIC_GEOMETRY`）。

### 3.2 传播

任一输入污染即结果污染；循环携带变量取并集直到不动点。

1. 算术 / 比较 / 逻辑 / 位运算：任一操作数污染 → 结果污染。
2. 单目运算（`-`、`+`、`!`、`~`、增量）：操作数污染 → 结果污染。
3. 数组 / 对象字面量：任一元素或属性污染 → 容器污染。
4. 成员访问：对象污染 → 成员污染；computed key 污染 → 取值污染。
5. 赋值 / 解构：右值污染 → 左值污染。
6. 函数调用：任一实参污染 → 返回值污染（保守；已知纯内建函数按白名单放宽）。
7. 隐式控制流：污染的条件（`if` / `switch` / `for` / `while` / 三元）使结构内**每个**赋值目标污染。
8. 函数参数 / 返回值：跨函数体传播；闭包捕获随之携带污染。
9. 库代码：第三方 `@faicad/*` 源码经同一扫描器，固定 strict。

### 3.3 判定结果

- 源值只到达非几何位置（日志、计时、调试）→ **放行**。
- 源值到达任一 sink（直接或经 §3.2，含隐式流）→ **拒绝**。

允许：

```js
console.log(Date.now())               // taint reaches console (non-sink) → allowed
const t = Date.now(); console.log(t)  // allowed
```

拒绝：

```js
const w = Date.now()                  // tainted
let part0 = cad.box(w, 10, 10)        // geometry-parameter sink → rejected
```

```js
let r = 10
if (Date.now() > 0) r = 20            // implicit flow: r tainted
let part0 = cad.sphere({ radius: r }) // rejected
```

```js
const t = Math.random()
cad.translate(part0, { offset: [t, 0, 0] }) // rejected
```

### 3.4 诚实边界

静态分析只能**发现**违约，不能**证明**确定。它覆盖显式与隐式流、跨函数与库边界，但无法校验引擎内部或宿主注入资源（字体 / 资产 / 内核）本身的确定性。真正的等价性由 §5 出口校验兜底。

## 4. 引擎与宿主责任

在用户代码门禁之外，以下非确定位于引擎或宿主内部，由实现负责消除，不属用户代码污染分析覆盖范围。

- 能力白名单（`S4_SAFE_GLOBALS`）把 `Math` / `Date` 作为整对象暴露，必须改为只暴露确定的 `Math` 常量与函数面，且不暴露 `Date`。
- 由随机 UUID 默认生成的几何身份必须改为确定性（内容哈希或确定性序号）。
- 写进操作历史 / 时间线的时间戳必须移除或改为确定性。
- 字体、资产、纹理必须随源码内容寻址打包；SDF / mesh / BREP 内核版本必须在文件头声明并固定。
- 双后端（AST 解释器 vs `new Function`）必须逐项对齐超越函数、别名、`instanceof` 与 `for-in` 遍历序。

## 5. 出口校验（跨内核 parity）

1. 每个 op 同时保留 BREP 与 mesh 两种参考几何。
2. 跨内核 / 引擎执行同一 `.fai.js`，按 §1.3 比对几何属性（顶点、法向、体积、面积、质心、bbox）。
3. parity 测试（`beforeAll` 内 `initOcctWasm()`）沿用此职责；比对阈值对齐 §1.3。
4. 任何随机源必须显式注入固定种子；确定性 PRNG 是参考范式。
